# Map styles

This branch hosts public MapLibre style JSON used by the private Obsidian vault.

## Abyssal

- Style: `assets/map-styles/abyssal.json`
- Base data: OpenFreeMap / OpenMapTiles / OpenStreetMap
- Palette: Abyssal / Carbon Cyan from `Obsidian-Vault/.obsidian/snippets/01_Core_System.css`
- Raw style URL: `https://raw.githubusercontent.com/llocphann/Veil/map-style-host/assets/map-styles/abyssal.json`
- Edit visually in Maputnik: `https://maputnik.github.io/editor/?style=https://raw.githubusercontent.com/llocphann/Veil/map-style-host/assets/map-styles/abyssal.json`

This host branch is intentionally separate from `Veil/main`.
